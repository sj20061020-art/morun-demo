# 墨润心源 V2

以笔墨润心境，以美育疗情绪。微信原生小程序 Demo + 配套静态网页预览 + 本机导师演示面板。

## 打开

- 微信：在微信开发者工具导入本目录中的 `project.config.json`，按需要填入自己的测试 AppID，编译 `miniprogram/`。
- 网页：打开 `web/index.html`；推荐使用同一 HTTP/HTTPS 地址。有 Node.js 时可运行 `node serve.cjs`。
- 导师网页：`web/index.html#admin-risk`，或从个人中心进入。

无需安装运行依赖，无后端服务器、无大模型 API、无外部运行资源请求。所有用户记录在当前环境的本地存储中。浏览器、小程序、V1 三者数据不互通。

## 目录

- `miniprogram/`：10 个学生页面、1 个辅助结果页、4 个导师演示页面，WXML/WXSS/JS/JSON 原生工程。
- `shared/model.js`：本地数据、问卷、问答词库、关键词工单、预约、授权与评语限制。
- `shared/brush.js`：Canvas 2D 多层书画引擎；与 `miniprogram/lib/` 同步。
- `web/`：学生和导师静态网页预览。
- `assets/`：本地山水、模拟头像和合成音乐。
- `fonts/`：宋体子集与字体授权。
- `docs/`：新旧差异、申报材料、导入指南和测试说明。
- `tests/domain.cjs`、`scripts/check.cjs`：无需第三方依赖的模型与工程检查。

## 演示边界

作品默认私密，主动授权后才显示在同机导师面板。关键词命中会暂停本次自动对话并保存本机工单；不会联系真实老师。预约回执只表示本机演示保存，不代表已向真实专家发送。专家资料、活动、排班和预置案例均为模拟，未经资质核验。

问卷为 12 条自编美育觉察问题，未经信效度验证；结果只作情绪参考，不作心理诊断或风险定性。工具不能替代专业心理咨询与治疗。

当前已完成浏览器流程测试、共享模型测试、原生结构与 API mock 检查；未使用项目方 AppID 进行微信工具真实编译或真机预览。

## 落笔成境 · 书法作品水墨动画

保存书法作品并选择情绪标签后，先写入作品库，再进入约 6.4 秒的水墨动画：山色展开，用户的真实笔迹逐步浮现。画面使用原始绘画层，自动框取笔迹范围，保留作品本身。支持跳过、重播、继续书写与查看作品；重播不重复保存。水墨画作仍按原流程保存。

动画完全通过 Canvas 2D 渲染，不需要视频服务或大模型；网页尊重系统减少动态效果设置，隐藏页面时暂停动画。原生小程序同步接入同一渲染模块 shared/ink-reveal.js。

## 正念书法页背景音乐

用户提供曲目：藤野游歌《看海的人》。保留整首约 3 分 51 秒，优化为 64 kbps 立体声 MP3（约 1.85 MB）。进入书法页尝试播放，按钮按实际播放状态切换为“暂停音乐 / 播放音乐”，暂停后从当前位置继续；离开或隐藏页面时暂停。浏览器拦截自动播放时，可点播放按钮或关闭鉴赏后开始。

原生小程序将实际书写页与音频放在 writing 分包，原 pages/write/write 入口保留并自动跳转。首页预载书写分包，各包音频与界面资源同包加载，无需外部音乐服务；import 工程时需保持整个 writing 目录。

网页在直接音频流迟迟无法读取元数据时，使用同源 HTTP Range 分段读取并组装完整 MP3，校验区间和字节长度后播放；不裁剪曲目、不上传用户数据、不依赖额外音乐服务。
