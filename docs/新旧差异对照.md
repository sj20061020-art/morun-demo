## 为保证 Demo 表述准确而作的必要调整

1. **工单不能声称已通知真人。** 无后端、无跨设备通信，因此提示为“已记录本机演示工单，未发送给远程导师”。不是远程人工服务，也没有实时人工值守。
2. **预约不能声称获得真实服务。** 回执明确显示“本机预约演示已保存、未实际发送”。导师切换状态仅演示业务流程。
3. **问卷不冒充验证量表。** 新方案未提供正式量表名称、授权、信效度和计分方案，采用 12 条自编美育觉察问题；4 维各 3 题，范围 0–9，不使用疾病或风险等级标签。
4. **专家信息不背书。** 郑红兰老师、陈琳按方案作为示例姓名；头像、排班、标签及资料均标为模拟、待核验、非真实入驻。陈琳的方案提供介绍也标明未经核验。
5. **导师权限是本机演示。** 作品必须主动授权才出现在导师列表，撤回立即隐藏；没有账号系统和服务端安全边界。
6. **新要求覆盖旧交互。** 新方案明确要求长幅书法滚动和多种笔触，所以 V2 恢复这些能力。外层保持手机应用框架，长列表和表单在内容区滚动。V1 的一屏、单笔刷版保留。
7. **旧版线下照片上传分类未沿用。** V2 按新清单采用书法、水墨、自测报告三类，原照片上传功能仍保留在 V1 备份。
