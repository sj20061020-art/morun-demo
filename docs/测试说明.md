## 未验证

- 未使用项目方微信 AppID 登录编译，也未进行微信真机预览或平台上传。
- API mock 不验证所有微信版本、机型的 Canvas、字体或音频差异。
- 画笔为 Canvas 分层视觉模拟，不是物理级水墨求解器。
- 规则问答和关键词匹配没有临床有效性，可能误报或漏报。
- 无后端，因此不验证真实跨设备通知、服务端鉴权、多人名额一致性或真实专家服务。

## 可重复检查

有 Node.js 时，可运行 `node tests/domain.cjs` 检查共享模型。`node scripts/check.cjs` 检查页面包、JSON 与共享文件同步情况。浏览器可按照《导入和答辩指南》重复操作。
