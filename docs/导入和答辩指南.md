# 导入与答辩演示指南

## 微信原生小程序

1. 解压完整源码，打开微信开发者工具，选择“导入项目”。
2. 选择包含 `project.config.json` 的 `morun-v2` 根目录，不要只选择 `web` 文件夹。
3. 使用自己的测试小程序 AppID，或工具允许的测试 / 游客模式。配置中的 `touristappid` 只是占位，不是已注册的小程序身份。
4. 工具读取 `miniprogramRoot: miniprogram/`。工程不需要安装 npm 运行依赖、不需要后端、不使用云开发、不配置大模型密钥。
5. 使用支持 Canvas 2D 和 `wx.createOffscreenCanvas` 的基础库与开发者工具版本。项目指定 3.9.3，可在工具中选择可用的较新稳定基础库。
6. 编译后从启动页进入。长幅书法需要滑动时，先点击“切换为滚动”，移动纸面后再切回书写。
7. 真机预览需要项目方 AppID、开发者权限与微信登录。当前源码交付不代表已上传微信平台、通过审核或发布上线。

## 浏览器预览与导师网页

- 打开 `web/index.html` 可体验学生端；推荐使用一个稳定 HTTP/HTTPS 地址，以确保本地存储来源一致。
- 导师入口在个人中心，也可进入 `web/index.html#admin-risk`。四个面板为 `#admin-risk`、`#admin-booking`、`#admin-experts`、`#admin-works`。
- 所有浏览器功能均为纯静态前端。可选的 `serve.cjs` 只提供本地静态文件预览，不是应用后端。
- 安装了 Node.js 时，在根目录运行 `node serve.cjs`，访问终端地址。
- 网页预览数据、小程序数据、V1 数据三者隔离，不会互相同步。使用同一浏览器地址切换学生与导师角色，才能看到本机联动。

## 建议答辩顺序

1. **启动与首页**：进入疗愈空间，介绍五个入口、随机问候和模拟活动轮播。
2. **自测**：完成 12 题，查看四维雷达图与参考文字，强调“自编觉察问题，不是诊断量表”。
3. **书法重点**：切换四种笔触，慢写 / 快写对比粗细；演示格线、长幅滚动、撤销和朱文印章；保存并选择“释怀”。
4. **水墨重点**：润水铺底、浓墨画主体、枯笔造纹理、淡墨叠加、点墨扩散；放置竹叶 / 月影，演示透明橡皮与恢复；保存情绪标签和备注。
5. **作品权限**：作品初始私密；切换到导师授权作品面板应看不到。回学生端主动授权后，导师端出现；添加美育评语；撤回后再次隐藏。
6. **预约**：提交一份团辅和一份专家预约演示，展示本机回执；导师端确认、完成或取消，个人中心查看状态。
7. **专家库**：新增或编辑示例资料；停用后学生端不再显示。说明数据是模拟且资质未核验。
8. **对话工单**：先发送普通的学习压力话题，展示预设回复；再使用明确标注为答辩测试的敏感词输入，展示会话暂停、无后续自动回复、本机工单和预约入口。
9. **导师工单**：查看触发会话快照，保存本机站内留言，标记跟进中 / 处理完成。预置 2 条案例都标注“模拟”。
10. **个人中心**：查看报告与预约、删除会话、管理默认隐私，展示完整免责声明。

## 演示时需要说清楚

- 所有“预约成功”都指本机演示保存，未发送给真实机构。
- 高危词命中不是专业风险评估；不可以声称已通知真人老师或完成真实转介。
- 导师视图是同机角色切换，不是账号鉴权或跨设备后台。
- 当前模型不使用外部 AI 服务。称为“AI 情绪陪伴”是交互命名，实质是本地规则问答模拟。
- 在真实教育或心理服务场景使用前，必须另行完成问卷与专家资质核验、未成年人隐私和服务流程设计；本 Demo 不能直接替代该过程。
