# 墨润心源——青少年书画美育情绪辅助工具

## 项目定位

“墨润心源”以书法、水墨和传统书画美育为媒介，为青少年提供可自主体验的情绪觉察与表达空间，作为线下初高中书画艺术团体辅导的线上配套 Demo。项目包含正念书法、水墨情绪创作、自编情绪觉察问卷、本地模拟陪伴对话、作品归档与授权、线下活动和专家预约演示。

本产品不提供心理诊断，不能替代专业心理咨询与治疗。预约、工单与导师面板均为本机流程模拟，不代表真实服务已经对接。

## 一、微信原生 Canvas 2D 与分层渲染

微信页面使用 `<canvas type="2d">`，通过节点查询取得 Canvas 对象，按设备像素比设置画布像素，并在逻辑坐标中绘制。通过 `wx.createOffscreenCanvas` 创建独立画层。核心引擎位于 `shared/brush.js`，构建到小程序的 `miniprogram/lib/brush.js`，网页预览也使用同一套绘制代码。

引擎包含纸底层 `paper`、已完成笔迹层 `base`、当前颜料层 `pigment`、当前水分层 `water` 和合成层 `composite`。纸底不参与橡皮擦；颜料与水分分别绘制后再合成，避免将背景误擦成白色。

## 二、速度采样、路径平滑与动态笔锋

输入点记录坐标、时间、压力（平台提供时）和笔触半径。相邻点距离与采样时间差得到速度，再使用低通滤波降低抖动；书写速度增加时半径减小，慢写时半径增大。半径自身也逐点平滑，避免粗细突然跳变。

路径采用中点与二次曲线插值，并按笔触半径加密采样，减少锯齿与折线感。抬笔后依据剩余路径长度渐变收尾。四类书法笔触通过宽度、透明度、干湿和笔刷纹理参数区分：硬笔楷书清晰、软笔行书顺滑、枯笔飞白虚实相间、浓墨重笔厚重饱满。

长幅画布以独立滚动视图承载。“书写 / 滚动”明确切换，降低触屏落笔与上下滑动的手势冲突。格线只用于练习引导，不进入导出作品；印章是可撤销的独立绘制指令。

## 三、水墨叠加、湿笔、枯笔与透明擦除

笔刷纹理由 Canvas 像素数据生成，不使用外部渲染服务。湿笔通过透明水分印记、淡墨扩展与短时变化模拟渗化；枯笔通过稀疏条带和局部缺墨模拟飞白。不同笔触采用 `source-over` 透明叠加，重叠位置会逐渐加深，不是用不透明颜色简单覆盖。

五种水墨画笔分别设定含水、透明度、尺度和干涩程度。点墨笔采用间隔落点形成滴墨扩散。低饱和颜料包含纯墨黑、青灰、赭石、黛蓝。远山、竹叶、云朵、月影为 Canvas 绘制的透明素材，可拖动后放置。

橡皮擦使用 `destination-out` 从笔迹层移除透明度，保留纸底与暗角。历史指令包含笔迹、素材、印章，支持撤销及水墨恢复。导出时先合成纸底，再合成完成的笔墨，生成本地图片。该机制是适合移动端 Demo 的视觉模拟，不是物理级流体或纸张渗透求解器。

## 四、本地预设陪伴对话与关键词工单

对话采用前端预设问答库，围绕书画、创作感受、压力和情绪表达进行字符串关键词匹配，不接入任何外部大模型 API。

输入实时与本地词库匹配，例如自伤、自杀、自残、活着没意思等。命中后先暂停当前会话，不再生成自动回复，再将会话快照保存到本机工单列表，显示明确的支持提示与专家预约演示入口。导师面板优先显示未完成工单；可查看会话、保存本机站内留言、协助预约和更新跟进状态。预置 2 条明确标注的模拟案例用于答辩。

关键词规则存在误报和漏报，不能替代专业风险评估。纯本地实现不能通知远程老师，因此界面明确显示“未实际发送、没有真人实时值守”，不声称已获得人工救助。

## 五、`wx.setStorage` 数据持久化

共享数据模型位于 `shared/model.js`。微信适配层直接使用 `wx.getStorage`、`wx.setStorage`、`wx.removeStorage`，数据不经过网络。元数据使用独立 V2 命名空间 `morun.v2.state`；每幅作品的图片以 Base64 分别存放在 `morun.v2.media.作品ID`，降低单个元数据键的增长压力。

Canvas 通过 `wx.canvasToTempFilePath` 导出 JPEG，再由本地文件系统读取 Base64，写入小程序 storage。为了展示或保存相册，会从 storage 生成本机图片缓存；删除作品或重置时也清理对应缓存。图片导出限制大小，存储失败会明确报错，不显示虚假的保存成功。

所有元数据变更通过顺序事务写入：只有底层写入成功后才更新内存状态，避免配额不足时出现“界面已更新但数据未保存”的情况。浏览器预览使用相同模型及另一套 localStorage 适配，不和微信小程序或 V1 共享记录。

## 六、作品权限与导师流程

作品初始默认仅自己可见，用户可逐幅授权或撤回；导师列表只读取已授权作品，提交评语时再次检查授权状态。评语进行诊断、药物治疗类词语拦截，并在界面提示仅从美育、构图和艺术表达角度参考。

预约模块维护活动名额、专家启用状态、可选时段与工单状态。重复预约和占用时段会被阻止；取消后释放本机演示名额。专家资料可以新增、编辑和停用。个人中心可以回看报告、管理会话、查看预约、管理隐私和清理本地数据。

这些权限和状态仅用于本机 Demo 演示。没有服务器、账号认证或跨设备授权服务，不宣称具备生产环境的服务端安全隔离或真实预约能力。
