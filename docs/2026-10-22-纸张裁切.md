# 纸张裁切与封面入口更新（2026-10-22）

网页每次新打开、刷新或从浏览器页面缓存恢复时先显示封面，点击进入后正常使用站内导航，不清除已有本地记录。

书法、水墨创作工具栏新增“裁切纸张”。可拖动四角调节选框、拖动内部移动选框，也可用宽高滑杆与整张、方形、横幅、竖幅快捷比例。取消不改变作品；确认后保留选框内的笔迹，画布与导出图片同步使用新尺寸。撤销可还原裁切，水墨页的恢复可重做裁切。清空笔迹时保留当前纸张尺寸。空白纸张裁切不会被当作已创作作品。

技术：Canvas2D 多层按选区裁切，裁切记录与笔触、素材共用可重放历史，不依赖图像上传、后端或第三方服务。H5 使用 Pointer Events，微信原生使用触摸事件，统一 CropSelection 算法；原生同步维护设备像素比和画布显示尺寸。

验证：node scripts/check.cjs；node tests/domain.cjs；node tests/crop.cjs。额外完成 390px 手机浏览器的书法/水墨选框拖动、裁切像素对齐、导出尺寸、撤销和继续绘画，320px 弹窗适配，以及微信 API 模拟的选框操作、撤销恢复和导出比例验证；未在真实微信开发者工具运行编译。
